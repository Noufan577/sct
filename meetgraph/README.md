# MeetGraph

MeetGraph is a local-first, evidence-backed commitment memory layer for Meetily.

## Planned Architecture

```text
Meetily
   ↓
MeetGraph ingestion
   ↓
Transcript normalization
   ↓
AI extraction
   ↓
Graph database
   ↓
Hybrid GraphRAG
   ↓
Evidence-backed answers
   ↓
Web UI / MCP
```

*Note: These components are planned architecture and not all implemented yet.*
